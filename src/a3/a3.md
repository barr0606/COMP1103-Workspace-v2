## Testing Summary and Analysis
The usability evaluation consisted of multiple testers completing three core tasks: (1) filter and search for an orange cat and apply to adopt it, (2) find and log in to the admin page, and (3) create an inquiry on the Contact Us page. These tasks were selected because they represent the primary user flows of the website and involve both front‑end and back‑end functionality. All participants also completed a post‑test questionnaire to capture perceived difficulty, usability, and open‑ended feedback.  
<br>
Across all testers, every task was completed successfully, demonstrating that the core functionality of the website is operational. However, the time required to complete each task varied significantly between individuals. For example, two testers completed Task 1 in 81 seconds and 88 seconds, Task 2 in 31 seconds and 32 seconds, and Task 3 in 54 seconds and 88 seconds. These results show that navigation‑based tasks (Task 2) were consistently fast, while tasks involving forms (Tasks 1 and 3) required more time and produced more hesitation.  
<br>
The adoption form was also described as overly simplified. A tester noted that more detailed questions would make the process feel more authentic, suggesting that the form may need additional fields.  
<br>
A major issue emerged during Task 2 on the admin page. Testers noted that the admin interface did not display the name of the animal they had applied for. Instead, only an ID number was shown. One tester said, “I just selected Indie, but it doesn’t say that,” highlighting a lack of clarity and feedback in the admin workflow. This issue directly affects the admin’s ability to verify applications and reduces trust in the system.  
<br>

## Iteration Description
Based on the usability evaluation, several updates will be made to improve clarity, consistency, and overall user confidence across the website. The first priority is improving the admin interface so that submitted applications display both the animal’s name and its ID. Because the project uses JSON files rather than a database, the PHP script that loads application data will be updated to read the selected animal’s name from the animals JSON file and merge it into the admin table output. The HTML table will then include a new column showing the animal name, making it easier for admins to identify which application belongs to which animal.  
<br>
The adoption form will also be expanded to better match user expectations. Additional fields will be added to the HTML form. The PHP handler will be updated to validate these new fields and append them to the JSON file where applications are stored. This will make the process feel more legitimate and closer to a real adoption workflow.
