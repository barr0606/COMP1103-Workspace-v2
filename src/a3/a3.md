# Usability Testing Report
## Usability Test Plan
The first set of tests was conducted by Fletcher. The first tester was an 18-year-old male. He does not have any physical impairments, he is studying a Bachelor of Education, and he has a job. He believes that he has good technology literacy, and his favourite animal is cats. The second tester was an 18-year-old female. She does not have any physical impairments, she is studying a Bachelor of Clinical Sciences, and she does not have a job. She believes that she has good technology literacy, and her favourite animal is a chameleon. 
<br>
<br>
Each tester was given 3 tasks to complete. The first task was for the tester to filter and search for an orange cat and apply to adopt it. The second task was to log in to the admin page. The last task was to create an inquiry on the Contact Us page. All tasks included some form of back-end functionality. For the first task, the search results page showed animals whose information was stored in a database, and the applications page sent the user information into a database, where the info would then be translated into the admin page. The second task's back-end functionality came from logging into the admin page by checking if the entered username and password matched those that already exist for the admin page. The final task’s back-end functionality came from getting data put into the inquiry section on the Contact Us page and sending it to a database.
<br>
<br>
For recording responses, a questionnaire was made in Google Forms, which contained 4 sections, one for tester data (i.e., name, age, gender, education, etc.), one with questions regarding the difficulty of each task during testing, one with post-test questions using SUS questions, and a final section that contained non-mandatory questions that were open ended regarding certain functions of the website (i.e., thoughts on layout/styling, anything the tester found easy/difficult to use, etc.).
